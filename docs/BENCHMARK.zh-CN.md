# 全场景真实验收基准

Token Forge 会同时公开通过、失败和待验证案例。v1 使用可公开再分发的自生成 fixtures，并真实调用本地适配器，不用 Mock 冒充转换结果。

## 本机实测结果

测试日期：2026-08-20。耗时是本机数据，原始案例中保留了逐项记录。

| 验收门 | 结果 |
|---|---:|
| 必选场景 | **18 / 18 通过** |
| 完整清单 | 19 通过 / 0 失败 / 1 待验证 |
| 必选案例受保护事实 | **51 / 51（100%）** |
| 全部本地案例受保护事实 | **53 / 53（100%）** |
| 必选案例来源锚点 | **11 / 11（100%）** |
| 必选案例表格单元格 | **9 / 9（100%）** |
| 两个受控 OCR 样本平均 CER | **0.00%** |
| 转写事实召回 | **6 / 6（100%）** |
| 自生成英语音视频平均 WER | **5.88%** |
| 七个上下文案例 | **按 Token 加权减少 89.57% / 宏平均 55.96%** |

两个小型代码/表格案例仍按设计 0% 直通，并真实计入平均值。新增规模样本分别得到：长文本 `509 → 94`（**81.53%**）、Python AST 依赖切片 `1,117 → 100`（**91.05%**）、500 行 CSV 可回算聚合 `2,943 → 84`（**97.15%**）。包含小样本后，各路线按 Token 加权减少率为：确定性文本 **74.15%**、代码上下文 **84.19%**、表格上下文 **96.00%**、本地模型文本 **83.30%**。

代码切片保留原始代码跨度、装饰器和名称依赖，并重新执行语法编译门；表格聚合覆盖全部 500 行并执行数值回算。以上仍是确定性生成样本，不代表任意语言调用图、任意真实表格或供应商计费结果。

实际覆盖了 Markdown、代码/表格安全直通、长文本最小事实覆盖、Python AST 切片、CSV 聚合、本地检索与压缩、DOCX/PPTX/XLSX/EPUB、数字 PDF、图片与扫描 PDF OCR、动态网页、本地音频和视频，以及 EML 邮件正文/附件清单与安全有界 ZIP 文本读取。19 个本地案例全部通过；公网平台案例默认 `Pending`。关键帧提取不等于视觉理解，视觉问答和盲评答案质量仍标记为待验证。

ZIP 路线不把成员解压到磁盘，拒绝路径穿越、符号链接、加密项，并限制为最多 256 项、单项 16 MiB、总解压体积 64 MiB、压缩比 100:1；嵌套压缩包只列清单、不递归。EML 路线不加载远程内容，也不把二进制附件伪装成已理解内容。以上数据仅适用于仓库内固定样本。

复现命令、原始结果和完整限制请参阅 [英文基准文档](BENCHMARK.md)、[`acceptance-manifest.json`](../benchmarks/acceptance-manifest.json) 与 [`acceptance-v1`](../benchmarks/results/acceptance-v1)。
