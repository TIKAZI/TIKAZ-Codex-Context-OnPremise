# 全场景真实验收基准

Token Forge 会同时公开通过、失败和待验证案例。v1 使用可公开再分发的自生成 fixtures，并真实调用本地适配器，不用 Mock 冒充转换结果。

## 本机实测结果

测试日期：2026-08-20。耗时是本机数据，原始案例中保留了逐项记录。

| 验收门 | 结果 |
|---|---:|
| 必选场景 | **15 / 15 通过** |
| 完整清单 | 16 通过 / 0 失败 / 1 待验证 |
| 必选案例受保护事实 | **41 / 41（100%）** |
| 全部本地案例受保护事实 | **43 / 43（100%）** |
| 必选案例来源锚点 | **9 / 9（100%）** |
| 必选案例表格单元格 | **9 / 9（100%）** |
| 两个受控 OCR 样本平均 CER | **0.00%** |
| 转写事实召回 | **6 / 6（100%）** |
| 自生成英语音视频平均 WER | **5.88%** |
| 四个可比较文本案例平均估算 Token 降幅 | **30.49%** |

四个文本案例不是市场代表性语料：两个高风险案例按设计 0% 压缩并安全直通，一个确定性检索案例减少 38.68%，一个 BGE + 重排 + LLMLingua-2 案例减少 83.30%。Token 数是确定性估算，不是 Codex 或模型供应商计费遥测。

实际覆盖了 Markdown、代码/表格安全直通、本地检索与压缩、DOCX/PPTX/XLSX/EPUB、数字 PDF、图片与扫描 PDF OCR、动态网页、本地音频和视频，以及 EML 邮件正文/附件清单与安全有界 ZIP 文本读取。16 个本地案例全部通过；公网平台案例默认 `Pending`。关键帧提取不等于视觉理解，视觉问答和盲评答案质量仍标记为待验证。

ZIP 路线不把成员解压到磁盘，拒绝路径穿越、符号链接、加密项，并限制为最多 256 项、单项 16 MiB、总解压体积 64 MiB、压缩比 100:1；嵌套压缩包只列清单、不递归。EML 路线不加载远程内容，也不把二进制附件伪装成已理解内容。以上数据仅适用于仓库内固定样本。

复现命令、原始结果和完整限制请参阅 [英文基准文档](BENCHMARK.md)、[`acceptance-manifest.json`](../benchmarks/acceptance-manifest.json) 与 [`acceptance-v1`](../benchmarks/results/acceptance-v1)。
