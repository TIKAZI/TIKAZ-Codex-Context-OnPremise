# 全场景真实验收基准

Token Forge 会同时公开通过、失败和待验证案例。v1 使用可公开再分发的自生成 fixtures，并真实调用本地适配器，不用 Mock 冒充转换结果。

所有转换、上下文、OCR、网页、音视频、模型与视觉场景的逐项数据，请查看[完整实测数据总表](RESULTS.md)。

## 本机实测结果

测试日期：2026-08-20。耗时是本机数据，原始案例中保留了逐项记录。

| 验收门 | 结果 |
|---|---:|
| 必选场景 | **18 / 18 通过** |
| 完整清单 | **20 通过 / 0 失败 / 0 待验证** |
| 必选案例受保护事实 | **51 / 51（100%）** |
| 全部本地案例受保护事实 | **53 / 53（100%）** |
| 必选案例来源锚点 | **11 / 11（100%）** |
| 必选案例表格单元格 | **9 / 9（100%）** |
| 两个受控 OCR 样本平均 CER | **0.00%** |
| 转写事实召回 | **6 / 6（100%）** |
| 自生成英语音视频平均 WER | **5.88%** |
| 固定视频精确关键帧路由 | **6 张源帧 → 2 张选中；跳过 4 张精确重复帧（66.67%）** |
| 独立 12 图视觉套件事实召回 | **OCR 37 / 37；VLM 37 / 37；组合 37 / 37** |
| 独立视觉套件主类型准确率 | **10 / 12（83.33%）** |
| 七个上下文案例 | **按 Token 加权减少 89.57% / 宏平均 55.96%** |

两个小型代码/表格案例仍按设计 0% 直通，并真实计入平均值。新增规模样本分别得到：长文本 `509 → 94`（**81.53%**）、Python AST 依赖切片 `1,117 → 100`（**91.05%**）、500 行 CSV 可回算聚合 `2,943 → 84`（**97.15%**）。包含小样本后，各路线按 Token 加权减少率为：确定性文本 **74.15%**、代码上下文 **84.19%**、表格上下文 **96.00%**、本地模型文本 **83.30%**。

代码切片保留原始代码跨度、装饰器和名称依赖，并重新执行语法编译门；表格聚合覆盖全部 500 行并执行数值回算。以上仍是确定性生成样本，不代表任意语言调用图、任意真实表格或供应商计费结果。

实际覆盖了 Markdown、代码/表格安全直通、长文本最小事实覆盖、Python AST 切片、CSV 聚合、本地检索与压缩、DOCX/PPTX/XLSX/EPUB、数字 PDF、图片与扫描 PDF OCR、动态网页、本地音频和视频，以及 EML 邮件正文/附件清单与安全有界 ZIP 文本读取。20 个场景均已通过。公开 B 站元数据案例在显式联网许可下用 `yt-dlp --dump-single-json` 成功，耗时 2.650 秒；未发现可用字幕，且没有下载媒体。此结果只验证该公开 URL，不代表登录态内容或全部平台均可访问。固定视频的 6 张关键帧经 SHA-256 精确去重后选中 2 张、跳过 4 张，减少 66.67% 的重复帧处理量。该比例不是图像 Token 节省、感知相似度或视觉准确率。

独立视觉套件在 2026-08-22 使用 12 张确定性 1280×720 自生成图片，覆盖中英文记录、设置页、数据看板、表格、柱状图、流程图、空间关系、警告框、发票、时间线和仓库示意场景。PP-OCRv5、Qwen3-VL 8B 和组合路线分别召回 **37 / 37** 个受保护事实；**12 / 12** 案例均在本地解决，主类型分类为 **10 / 12**。相同设置连续两轮的逐案例事实和类型结果完全一致，Ollama 报告的 VLM 总耗时分别为 48.852 秒和 48.755 秒。两项稳定错误是把扁平设置页和数据看板归为 `document`，而不是 `ui`；事实召回不受影响。

这组数据只证明固定清晰合成样本，不代表真实世界图片、手写内容、退化扫描、自然视频、任意图表或下游问答质量。模型本地 prompt 计数不是 Codex 输入 Token；Codex 图像 Token 节省仍为 `Pending provider telemetry`。

ZIP 路线不把成员解压到磁盘，拒绝路径穿越、符号链接、加密项，并限制为最多 256 项、单项 16 MiB、总解压体积 64 MiB、压缩比 100:1；嵌套压缩包只列清单、不递归。EML 路线不加载远程内容，也不把二进制附件伪装成已理解内容。以上数据仅适用于仓库内固定样本。
